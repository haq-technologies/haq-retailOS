HAQ Retail OS

Set up this device

Do this once on each counter PC and on the owner's laptop or phone. It takes about five minutes. You need the code HAQ support makes on the server for this device.

1 Trust the shop's certificate

The shop server proves who it is with a certificate from the shop's own authority. Windows must trust that authority once, or Chrome warns that the connection is not private.

A phone, a Mac, or doing it by hand

Download the certificate

  1. Windows by hand: open the downloaded file, choose Install Certificate, then Local Machine, then "Place all certificates in the following store", Browse, Trusted Root Certification Authorities, OK, Next, Finish.
  2. Android: Settings, Security, More security settings, Install from device storage, CA certificate, then choose the downloaded file.
  3. iPhone: open this page in Safari and download the certificate, choose Allow; then Settings, Profile Downloaded, Install. Then Settings, General, About, Certificate Trust Settings, and turn on "HAQ Retail OS shop authority".
  4. Mac: open the downloaded file; in Keychain Access put it in System, open it, and under Trust choose Always Trust.

2 Register this device

On the server, HAQ support runs sudo haq enrol T01 for counter 1 (T02 for counter 2, D01 for the owner's laptop or phone) and gives you the code it shows, such as 4827-1093. A code works once, for 30 minutes.
